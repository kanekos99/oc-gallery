- Add package.json
- Add .eleventy.js
- Run npm install
- Add `/node_modules` and `/public` to .gitignore
- Create a `src` folder and move templates into `src` folder
- Move `styles`, `scripts` and `assets` into `src` folder also
- Make templates into .njk files
- Update ALL links to be in this format (for scripts, CSS sheets and images):
```
<script src="{{ '/scripts/pagination.js' | url }}"></script>
```
```
href="{{ '/styles/main.css' | url }}"

```
- Run npm run start
